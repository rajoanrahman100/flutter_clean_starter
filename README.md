# Flutter Clean Starter

A powerful command‑line tool to generate Flutter projects pre‑configured with **Clean Architecture**, **BLoC** state management, and **Dio** for networking. The generator sets up a modular folder structure, essential dependencies, and starter code so you can focus on business logic right away.

## 📦 Installation
```bash
# Activate globally via Dart pub
dart pub global activate flutter_scaffold_cli
# Ensure the binary is on your PATH
export PATH="$(dart pub global list | grep flutter_scaffold_cli | awk '{print $2}')/bin:":$PATH
```

## 🚀 Usage
```bash
flutter_scaffold create <project_name> [options]
```
Options:
- `--org <org>` – Specify the Android/iOS organization identifier (e.g., `com.example`).
- `--path <path>` – Destination directory (defaults to current working directory).
- `--no-bloc` – Skip BLoC setup if you prefer another state‑management solution.
- `--no-dio` – Omit Dio and use the default `http` package.

The command scaffolds:
- **lib/** – Core layers (`data`, `domain`, `presentation`).
- **bloc/** – Ready‑to‑use Cubits/Blocs for each feature.
- **dio/** – Configured Dio client with interceptors and error handling.
- **pubspec.yaml** – Pre‑added dependencies (`flutter_bloc`, `dio`, `equatable`, etc.).

## ✨ Features
- **Clean Architecture** separation of concerns.
- **BLoC** pattern with generated Cubit/Bloc files.
- **Dio** networking layer with base options and logging.
- Customizable project name, organization, and output path.
- Fully lint‑ed and ready for CI integration.
